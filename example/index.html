prosemirror-freeze-plugin

Type freely between frozen sections. Try to delete a frozen section with Backspace, Delete, Cut, or by selecting and typing — none of it should land. Insert a marker at start/end to open the boundary for editing. Toggle freeze mode off to edit frozen text in place.

Shortcuts: Ctrl/Cmd+B freezes the selection (or unfreezes when adjacent to frozen) · Ctrl/Cmd+Shift+B bold · Ctrl/Cmd+I italic · Ctrl/Cmd+Shift+L toggle freeze mode
